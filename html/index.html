Accessibility notes

These pages are built for screen-reader and keyboard use:

  • A skip link jumps straight to the main content; the page is divided into labelled banner, navigation and main landmarks.
  • Each page has exactly one h1, and headings never skip a level, so a heading list is a usable table of contents.
  • Every table carries a caption and scope="col" headers. A table that scrolls sideways becomes a focusable region announced as such.
  • ASCII schematics are exposed as a single described image instead of a wall of box-drawing characters.
  • The theme button and copy button have explicit accessible names, and actions are announced through a live region.
  • Focus is always visible, motion respects prefers-reduced-motion, and colours follow prefers-color-scheme.
